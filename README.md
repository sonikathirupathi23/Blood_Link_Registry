# BloodLink – Blood Donor Registry

BloodLink is a web-based Blood Donor Registry System developed using Spring Boot, MySQL, HTML, CSS, and JavaScript.

The system helps manage blood donors, blood groups, donor availability, and blood donation records through a simple and professional web interface.

## Features

- Donor registration and management
- Blood group management
- Search donors by blood group and location
- Donor eligibility tracking
- Blood donation record management
- Dashboard with donor and blood group statistics
- REST API using Spring Boot
- MySQL database integration
- Responsive web interface

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Maven

## Project Structure

src/main/resources/static/
- index.html
- style.css
- script.js

## Backend

The application provides REST APIs for managing donors, blood groups, and donation records.

## Database

MySQL is used as the database for storing donor, blood group, and donation information.
